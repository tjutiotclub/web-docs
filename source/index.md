# 天津理工大学物联网科技协会开放资源平台

这里整理协会在嵌入式学习、实验教学和工程实践中积累的资料。文档强调可复现和可维护：不仅给出操作步骤，也尽量说明配置依据与验证方法。

内容从 C 语言和基础开发环境开始，逐步进入 STM32 外设、Linux 工具链和项目实践。第一次访问时，建议按照下面的顺序学习。

```{tip}
**刚开始学习？** 先完成 C 语言基础，再进入 STM32 教程。每完成一步，都应通过编译结果、串口输出或硬件现象确认结果。
```

## 如何使用这些文档

1. 从对应栏目的索引页开始，按推荐顺序阅读。
2. 在真实环境中运行示例，不要只复制代码或命令。
3. 用编译结果、终端输出或硬件现象验证每一步。
4. 遇到版本差异时，以芯片手册、工具官方文档和项目实际配置为准。
