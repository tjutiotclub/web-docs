# 协会各组学习路线

本文给出算法组、电控组和机械组的建议学习顺序。各阶段的“完成后能够”表示可以在指导下开始相应实践，不代表只完成清单就能独立承担完整项目。学习时应根据项目需求补充数学、工程安全和测试知识。

## 算法组学习路线

> 算法组主要负责机器人视觉、无人机视觉、自主飞行算法及伴飞开发，目标是逐步具备视觉算法开发与竞赛项目协作能力。

---

### 第一阶段：Python 基础

学习内容：

- Python 基础语法
- 函数
- 面向对象
- 常用数据结构
- pip
- 虚拟环境

完成后能够：

- 编写 Python 程序
- 阅读项目代码
- 使用第三方库

推荐项目：

- 图片处理
- 数据处理
- 小工具开发

---

### 第二阶段：OpenCV 与视觉基础

学习内容：

- OpenCV
- 图像读取
- 图像变换
- HSV
- 二值化
- 边缘检测
- 轮廓识别

理解：

- 什么是计算机视觉
- 图像是如何处理的
- 相机工作原理

推荐项目：

- 颜色识别
- 二维码识别
- 目标定位

---

### 第三阶段：YOLO 目标检测

学习内容：

- 深度学习基础
- YOLO 使用
- 模型训练
- 模型部署

完成后能够：

- 使用 YOLO 进行目标检测
- 完成实时识别
- 为伴飞算法提供目标位置

推荐项目：

- 人体检测
- 车辆检测
- 目标跟踪

> 完成 Python、OpenCV 和 YOLO 基础后，可以在指导下开发桌面端视觉原型。完整的伴飞系统还需要学习相机标定、坐标变换、状态估计、飞控通信、控制与安全测试。

---

### 第四阶段：Linux 开发环境

学习内容：

- Ubuntu
- Shell
- Git
- SSH
- CMake
- VSCode Remote

学习目标：

- 熟悉 Linux 开发环境
- 学会项目管理
- 配置无人机开发环境

推荐实践：

- 安装 Ubuntu
- 配置开发环境
- 学习 Git 协作

---

### 第五阶段：ArduPilot（AP）SITL 仿真

学习内容：

- ArduPilot（AP）
- Mission Planner
- MAVLink
- MAVProxy
- DroneKit
- SITL 仿真

学习目标：

- 搭建 AP 仿真环境
- 理解无人机控制流程
- 学会与飞控通信

推荐项目：

- 起飞
- 降落
- 自动航点
- 自动伴飞

> 此阶段可以将前面开发的视觉算法接入 ArduPilot，实现伴飞算法在仿真环境中的验证。

---

### 第六阶段：ROS 集成

学习内容：

- ROS
- Topic
- Service
- Node
- Launch
- RViz

学习目标：

- 将视觉算法模块化
- 建立无人机软件架构
- 与飞控进行数据交互

推荐项目：

- 图像节点
- 飞控通信节点
- 目标跟踪节点
- 伴飞节点

---

### 第七阶段：C++ 进阶与工程优化

学习内容：

- C++11/14/17
- STL
- 智能指针
- 多线程
- OpenCV C++
- ROS C++
- CMake

学习目标：

- 将 Python 原型迁移到 C++
- 提升程序运行效率
- 构建完整工程项目

推荐项目：

- C++ 版本伴飞算法
- ROS+C++ 集成
- 实机部署
- 性能优化

---

### 学习路线总览

```text
Python
    │
    ▼
OpenCV
    │
    ▼
YOLO
    │
    ├──────────────► Windows 伴飞算法开发
    │
    ▼
Linux
    │
    ▼
ArduPilot（AP）SITL 仿真
    │
    ▼
ROS 集成
    │
    ▼
C++ 工程化
    │
    ▼
无人机实机部署
```

---

### 实践方向

完成相应练习并通过项目验证后，可以在团队中参与以下方向：

- RoboMaster 视觉算法
- 无人机伴飞开发
- YOLO 目标检测
- AP 自动任务开发
- ROS 软件架构开发
- C++ 工程化开发
- 无人机视觉导航
- 无人机自主飞行算法





## 电控组学习路线

> 电控组主要负责 RoboMaster 机器人控制系统开发，包括嵌入式开发、电机控制、通信协议及整车控制，目标是逐步具备控制模块开发和竞赛协作能力。

---

### 第一阶段：嵌入式开发基础

学习内容：

- C 语言基础
- STM32 基础
- CubeMX
- HAL 库
- GPIO
- UART
- PWM
- 定时器
- 中断

学习目标：

- 能够编写 STM32 程序
- 能够驱动常用外设
- 熟悉开发流程

> 完成第一阶段并通过基础实验后，可以在指导下参与简单模块的开发与调试。

---

### 第二阶段：项目实践

学习内容：

- RoboMaster 开发框架
- CAN 通信
- DJI 电机控制
- PID 控制
- 遥控器数据解析
- 电源管理

学习目标：

- 完成机器人基础控制
- 能够调试底盘和云台
- 理解整车控制流程

推荐项目：

- 底盘控制
- 云台控制
- 电机驱动

---

### 第三阶段：进阶开发

学习内容：

- FreeRTOS
- 多任务开发
- 裁判系统通信
- 模块化设计
- 调试技巧
- 代码规范

学习目标：

- 独立负责机器人功能模块
- 与算法组、机械组协同开发
- 提升系统稳定性

推荐项目：

- 英雄机器人
- 步兵机器人
- 哨兵机器人
- 工程机器人

---

### 学习路线总览

```text
STM32 基础
    │
    ▼
参与 RoboMaster 项目开发
    │
    ▼
CAN + 电机控制 + PID
    │
    ▼
FreeRTOS + 裁判系统
    │
    ▼
独立负责机器人模块
    │
    ▼
竞赛实战
```

---

### 实践方向

完成相应练习并通过项目验证后，可以参与：

- RoboMaster 机器人电控开发
- 底盘控制
- 云台控制
- 电机驱动开发
- 裁判系统通信
- 嵌入式系统开发
- 比赛现场调试与维护





## 机械组学习路线（分方向培养）

> 机械组主要负责 RoboMaster 机器人、无人机及竞赛设备的结构设计、制造与装配，目标是逐步掌握从设计到装配调试的完整流程。
>
> 学习路线采用 **"公共基础 + 专业方向 + 高级能力"** 的培养模式，在完成基础能力培养后，可根据兴趣选择 **机器人方向** 或 **无人机方向** 深入学习。

---

### 第一阶段：机械基础（公共）

学习内容：

- 工程制图基础
- 常用机械结构
- 常用材料
- 紧固件认识
- 公差与配合
- 常见传动方式（齿轮、同步带、链传动等）

学习目标：

- 能够看懂机械图纸
- 认识常见机械零件
- 理解基本机械设计原理
- 掌握常见机构组成

---

### 第二阶段：SolidWorks 建模（公共）

学习内容：

- 草图绘制
- 三维建模
- 装配体设计
- 工程图
- 配置管理
- 基础仿真（可选）
- 钣金设计（可选）

学习目标：

- 独立完成零件建模
- 绘制工程图
- 完成装配设计

推荐项目：

- 电机固定座
- 云台支架
- 相机支架
- 联轴器

---

### 第三阶段：加工与制造（公共）

学习内容：

- 3D 打印
- 激光切割
- CNC 加工
- 碳板加工
- 工具使用
- 零件装配
- 常见加工误差

学习目标：

- 能够独立完成零件加工
- 将设计转化为实物
- 完成基础装配与维修

---

### 第四阶段：专业方向（二选一）

完成前三阶段后，可根据兴趣和项目需求选择一个方向深入学习。
