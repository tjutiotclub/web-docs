# Shell脚本基础

Shell 脚本可以将一组终端操作组织成可重复执行的工具。本章面向编译、部署、测试和日志收集等工程任务。

## 学习目标

- 编写并执行 Bash 脚本。
- 正确使用变量、参数和引号。
- 根据退出状态判断命令是否成功。
- 使用条件、循环和函数组织脚本。
- 为脚本增加输入检查与错误处理。

## 脚本结构

```bash
#!/usr/bin/env bash
```

介绍 Shebang、执行权限，以及直接执行脚本与使用 `bash script.sh` 的区别。

## 变量与引号

本节介绍变量赋值、环境变量、命令替换，以及单引号和双引号对变量展开的影响。

## 参数与退出状态

介绍 `$0`、`$1`、`$#`、`$@` 和 `$?`，让脚本能够接收输入并把执行结果返回给调用者。

## 条件判断

使用 `if`、`case` 和 `test` 判断字符串、数字、文件与目录状态。

## 循环与函数

使用 `for`、`while` 和函数消除重复命令，并保持每个函数职责单一。

## 错误处理

介绍显式检查退出状态、错误消息和清理临时文件。`set -e` 可辅助发现错误，但不能代替关键步骤的明确判断。

## 本章实践

编写一个项目构建脚本：检查源目录、创建构建目录、运行构建命令、判断结果并将产物复制到输出目录。

## 本章检查点

- 能解释脚本参数和退出状态。
- 能正确处理包含空格的路径变量。
- 能让失败的步骤向调用者返回非零状态。
