# 用户、用户组与文件权限

Linux 使用用户、用户组和权限位控制资源访问。本章以解决开发中常见的 `Permission denied` 为目标。

## 学习目标

- 理解用户、用户组和 root 用户。
- 读懂 `rwx` 权限表示。
- 使用 `chmod` 和 `chown` 调整权限与所有者。
- 正确使用 `sudo`。
- 解决串口等设备文件的访问权限问题。

## 用户和用户组

介绍 UID、GID、主用户组和附加用户组，使用 `id`、`whoami` 和 `groups` 查看当前身份。

## 读懂权限

通过 `ls -l` 输出说明文件类型、所有者、所属组，以及所有者、用户组和其他用户三组权限。

## 文件与目录权限

分别解释 `r`、`w`、`x` 对普通文件和目录的不同意义，说明为什么目录缺少执行权限时无法进入或访问其中的文件。

## 修改权限与所有者

```bash
chmod
chown
chgrp
```

同时介绍符号表示和数字表示，避免使用无边界的 `chmod 777` 解决权限问题。

## sudo与root

说明 `sudo` 的授权模型、命令作用范围和审计意义，并建立按需提升权限的使用习惯。

## 串口权限

以 `/dev/ttyUSB0` 为例，介绍设备节点的所有者和用户组，并说明通过加入 `dialout` 组获得长期访问权限的方式。

## 本章实践

创建一个脚本文件，观察它在添加执行权限前后的行为；查看串口设备节点的权限并判断当前用户是否具有访问条件。

## 本章检查点

- 能读懂 `-rwxr-x---`。
- 能解释文件权限与目录权限的区别。
- 遇到权限错误时能先定位所有者、用户组和权限位，而不是直接扩大所有权限。
