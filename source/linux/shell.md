# Shell命令基础

本章介绍 Linux 终端中最常用的命令，以及命令之间的组合方法。路径与目录结构在上一章学习，权限、进程和脚本分别在后续章节展开。

## 学习目标

- 掌握文件和目录的查看、创建、复制、移动与删除。
- 使用帮助系统查询陌生命令。
- 使用通配符批量匹配文件。
- 理解标准输入、标准输出和标准错误。
- 使用管道与重定向组合简单任务。

## 命令的基本结构

```text
命令 [选项] [参数]
```

本节介绍短选项、长选项、位置参数以及命令对大小写的处理方式。

## 文件与目录操作

需要掌握的命令包括：

```bash
pwd
ls
cd
mkdir
touch
cp
mv
rm
```

删除和覆盖操作不可自动恢复。执行前应使用 `pwd`、`ls` 等命令确认目标路径。

## 查看文本内容

```bash
cat
less
head
tail
wc
```

本节重点解释一次性输出、分页阅读和持续查看日志之间的区别。

## 搜索文件与内容

```bash
find
grep
which
```

学习如何按名称查找文件、在文本中搜索关键词，以及确认命令对应的可执行文件位置。

## 通配符

本节介绍 `*`、`?` 和字符集合的匹配规则，并区分 Shell 展开与命令自身的参数处理。

## 管道与重定向

```bash
command > output.txt
command >> output.txt
command 2> error.txt
command1 | command2
```

本节说明标准输入、标准输出、标准错误以及覆盖写入、追加写入和管道传递。

## 获取帮助

```bash
command --help
man command
```

学习从命令帮助中找到选项含义、参数格式和常用示例。

## 本章实践

创建一个练习目录，在其中生成多个文本文件，使用通配符列出指定文件，通过 `grep` 搜索内容，再利用管道统计匹配行数。

## 本章检查点

- 能安全地复制、移动和删除文件。
- 能从 `man` 或 `--help` 中查询命令用法。
- 能解释 `>`、`>>`、`2>` 和 `|` 的区别。
