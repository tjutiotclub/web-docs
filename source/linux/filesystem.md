# Linux文件系统与路径

Linux 将磁盘文件、设备和部分内核运行信息组织在同一棵目录树中。本章解释路径、文件类型、目录结构和挂载关系。

## 学习目标

- 区分绝对路径与相对路径。
- 理解 Linux 单一目录树结构。
- 认识普通文件、目录、链接和设备文件。
- 理解 `/dev`、`/proc` 和 `/sys` 在嵌入式开发中的作用。
- 建立挂载点的基本概念。

## 路径表示

本节介绍根目录 `/`、当前目录 `.`、上级目录 `..` 和用户主目录 `~`，并通过目录切换练习比较绝对路径和相对路径。

## 常见目录

| 目录 | 主要用途 |
| --- | --- |
| `/home` | 普通用户的个人目录 |
| `/etc` | 系统和服务配置 |
| `/usr` | 用户空间程序、库和共享资源 |
| `/var` | 日志、缓存等经常变化的数据 |
| `/tmp` | 临时文件 |
| `/dev` | 设备文件 |
| `/proc` | 进程和内核运行信息 |
| `/sys` | 设备、驱动和内核对象信息 |

## 文件类型

本节介绍普通文件、目录、符号链接、字符设备和块设备，并学习使用 `ls -l` 与 `file` 判断文件类型。

## 链接

介绍硬链接与符号链接的用途，重点掌握 `ln -s` 创建符号链接，以及链接目标移动或删除后的表现。

## 挂载

本节解释磁盘分区、文件系统与目录树之间的关系，介绍 `mount`、`umount`、`df` 和 `lsblk` 的只读查询用法。

## 嵌入式设备节点

通过 `/dev/ttyUSB0`、`/dev/ttyACM0`、`/dev/i2c-*` 等例子，理解硬件设备、内核驱动与用户空间设备文件之间的关系。

## 本章实践

绘制当前系统的关键目录关系，查看已挂载文件系统，并在连接串口模块前后比较 `/dev` 目录的变化。

## 本章检查点

- 能根据当前位置写出同一文件的绝对路径和相对路径。
- 能说明 `/dev`、`/proc`、`/sys` 中的内容为何不等同于普通磁盘文件。
- 能解释“把文件系统挂载到目录”的含义。
