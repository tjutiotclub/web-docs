# Linux开发工具链

本章将 C 语言知识连接到 Linux 工程实践，介绍程序从源代码到可执行文件的过程以及常用构建和调试工具。

## 学习目标

- 理解预处理、编译、汇编和链接四个阶段。
- 使用 GCC 编译多文件 C 程序。
- 理解头文件、静态库和动态库的基本作用。
- 使用 Make 或 CMake组织项目构建。
- 使用 GDB 完成基础调试。

## GCC编译流程

通过 `gcc -E`、`gcc -S`、`gcc -c` 和最终链接命令观察各阶段产物，并理解常见编译错误与链接错误的区别。

## 编译选项

重点使用：

```bash
-Wall -Wextra -g -O0 -I -L -l
```

解释警告、调试信息、优化、头文件目录和库目录的作用。

## 多文件工程

结合声明与定义，构建包含多个 `.c` 和 `.h` 文件的小型程序，并理解目标文件如何参与链接。

## 库文件

介绍静态库、动态库、运行时搜索路径和 ABI 的基本概念，使用 `ar`、`ldd` 和 `file` 检查产物。

## Make

学习目标、依赖、命令和时间戳更新规则，编写能够增量构建多文件程序的基本 Makefile。

## CMake

理解 CMake 是构建系统生成器，掌握配置、构建和指定构建目录的基本流程。

## GDB

学习断点、单步执行、查看变量、调用栈和继续运行，能够定位简单的崩溃与逻辑错误。

## 二进制检查工具

```bash
file
ldd
readelf
nm
size
```

这些工具用于确认文件格式、目标架构、依赖库、符号和各段大小。

## 本章实践

构建一个多文件 C 项目，为它编写 Makefile，在 GDB 中设置断点并检查变量，最后使用 `file` 和 `readelf` 查看可执行文件。

## 本章检查点

- 能区分编译错误与链接错误。
- 能独立构建多文件 C 程序。
- 能使用 GDB 找到程序停止位置和调用路径。
