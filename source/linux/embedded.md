# 嵌入式Linux系统概览

本章将前面的 Linux 使用与开发知识放入完整的嵌入式系统中，说明设备从上电到运行应用程序经历的主要阶段。

## 学习目标

- 理解嵌入式 Linux 与单片机程序的主要差异。
- 认识 Bootloader、Linux 内核、设备树和根文件系统。
- 理解内核驱动与用户空间程序的边界。
- 建立后续学习系统构建和驱动开发所需的整体框架。

## 从上电到用户程序

```text
BootROM
   ↓
Bootloader
   ↓
Linux Kernel + Device Tree
   ↓
挂载 Root Filesystem
   ↓
启动 init/systemd
   ↓
运行系统服务和用户程序
```

## Bootloader

Bootloader 完成早期硬件初始化、加载内核和设备树，并向内核传递启动参数。常见嵌入式 Linux Bootloader 为 U-Boot。

## Linux内核

内核负责进程调度、内存管理、设备驱动、文件系统和网络等核心功能，并向用户空间提供系统调用接口。

## 设备树

设备树描述板级硬件资源及其连接关系，使内核驱动能够获得寄存器地址、中断、时钟和 GPIO 等配置信息。

## 根文件系统

根文件系统包含动态库、命令、配置文件、系统服务和用户程序。内核启动后必须挂载可用的根文件系统，才能进入完整用户空间。

## 驱动与应用程序

驱动在内核空间管理硬件，应用程序在用户空间通过设备文件、系统调用或子系统接口使用硬件。GPIO、I2C、SPI、串口等外设在 Linux 中通常通过统一的内核接口访问。

## 系统构建工具

Buildroot 和 Yocto 可以组合工具链、Bootloader、内核与根文件系统，生成完整系统镜像。它们属于后续系统构建阶段。

## 与STM32裸机开发的联系

STM32 裸机程序通常直接调用 HAL 操作寄存器和外设；嵌入式 Linux 应用通过操作系统接口访问由驱动管理的硬件。两者共享数字电路、通信协议和 C 语言基础，但软件层次与运行模型不同。
