# 软件包与开发环境管理

Linux 发行版通过软件包管理器安装、升级和删除软件。本章以 Ubuntu 和 APT 为主要示例。

## 学习目标

- 理解软件包、软件源和依赖关系。
- 使用 APT 查询、安装、升级和删除软件。
- 区分系统软件包与项目依赖。
- 能够确认命令由哪个软件包提供。

## 软件包管理体系

本节介绍 DEB 软件包、APT 软件源、包索引和依赖解析之间的关系。

## 常用APT命令

```bash
sudo apt update
apt search keyword
apt show package
sudo apt install package
sudo apt remove package
```

解释更新软件包索引与升级已安装软件之间的区别。

## 查询已安装内容

介绍 `dpkg -l`、`dpkg -L` 和 `dpkg -S`，用于确认软件包状态、安装文件和文件归属。

## 开发工具包

说明编译器、头文件和开发库通常分开打包，以及 `build-essential`、名称以 `-dev` 结尾的软件包在编译 C/C++ 项目时的作用。

## 环境隔离

简要区分系统包管理器、Python 虚拟环境和 Conda 环境。系统工具由系统包管理器维护，项目级依赖由对应语言或项目环境管理。

## 本章实践

查询并安装一个小型命令行工具，确认它的可执行文件位置、所属软件包和版本，然后使用包管理器移除。

## 本章检查点

- 能解释 `apt update` 为什么不会直接升级软件。
- 能查询软件包的说明和安装文件。
- 能区分运行库与开发包。
