# 网络与远程连接

嵌入式开发经常需要通过网络连接开发板、服务器和代码托管平台。本章建立完成远程开发所需的网络基础。

## 学习目标

- 理解 IP 地址、子网、网关、DNS 和端口。
- 查看本机网络接口和监听端口。
- 使用常见命令定位网络故障。
- 使用 SSH 登录远程设备并安全传输文件。

## 网络基本概念

本节介绍局域网、公网、IPv4 地址、端口和客户端/服务器关系，并说明域名解析在连接过程中的位置。

## 查看网络状态

```bash
ip addr
ip route
ss -lntup
```

学习识别网卡地址、默认路由和正在监听的服务端口。

## 连通性诊断

```bash
ping
curl
nslookup
traceroute
```

按“本机接口—网关—IP连通—DNS解析—应用端口”的顺序定位问题。

## SSH远程登录

```bash
ssh user@host
```

介绍首次连接的主机指纹、密码登录、密钥登录和 `~/.ssh/config` 的基本用途。

## 文件传输

```bash
scp local_file user@host:/remote/path/
scp user@host:/remote/file ./
```

根据传输方向确认源路径和目标路径，避免覆盖错误位置。

## 防火墙与云安全组

说明应用监听端口、本机防火墙和云平台安全组是三层不同的访问条件。

## 本章实践

通过 SSH 登录一台 Linux 主机，上传一个文件，在远端确认校验值，再将结果文件下载到本地。

## 本章检查点

- 能查看设备 IP 和默认路由。
- 能判断问题发生在网络、DNS、端口还是应用服务。
- 能使用 SSH 密钥和 SCP 完成远程开发的基本操作。
